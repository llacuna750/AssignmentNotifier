1.	Core Features (Must Have)

•	Assignment Creation / Pending to complete: A simple input form to add assignment with a title and due date.
•	Edit assignment creation: You can edit the existing assignment create.
•	Status Updates: A toggle button to mark tasks as "In Progress" or "Completed."
•	Data Persistence: Cloud storage so user data saves automatically and persists across sessions.  (local storage locally)
•	Assignment Dashboard: It display pending assigment and due date


2.	Deferred Features (Nice to Have / Phase 2)

•	Push Notifications: Reminders sent via messager  or email digests.
•	Dark Mode: A secondary visual theme for low-light environments.
